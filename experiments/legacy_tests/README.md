# Historical validation scripts

These scripts are the live tests behind earlier entries of `experiments.jsonl` and `CHANGELOG.md`. They are kept as
the record of how each change was measured. They reference the author's projects and benchmark folders
(`<projects>`, `<studio>`, `<forge>` stand for local paths), so they do not run on another machine as they are.

For a test that runs anywhere, use `tests/run_selftest.py`.
